邻接矩阵 Adjacency Matrix
用二维数组存图
  • 定义：graph[i][j] 表示顶点 i 到 j 的边信息（0/1 或权值）
  • 无向图：矩阵对称，可只存上三角
  • 空间复杂度：O(V²)，适合稠密图
  • 查边：查询两点是否有边 O(1)
💡 提示：若边不存在通常用 ∞ 或 0 表示，根据题目约定

# Python 邻接矩阵（带权图） INF = float('inf') V = 5 # 顶点数 # 初始化：对角线为 0，其余为 INF graph = [[0 if i == j else INF for j in range(V)] for i in range(V)] # 批量添加边 edges = [ (0, 1, 2), # A -> B (2) (0, 2, 4), # A -> C (4) (1, 2, 1), # B -> C (1) (1, 3, 7), # B -> D (7) (2, 4, 3), # C -> E (3) (3, 4, 2), # D -> E (2) ] for u, v, w in edges: graph[u][v] = w
邻接表 Adjacency List
为每个顶点维护一个邻居列表
  • 定义：为每个顶点维护一个列表，存储其邻接顶点
  • 空间复杂度：O(V + E)，适合稀疏图
  • 查询邻居：遍历某顶点的所有邻居 O(degree)
  • 工程首选：绝大多数实际场景使用邻接表
💡 提示：绝大多数工程 / 竞赛场景都用邻接表，空间效率高且实现简单

有向图 vs 无向图

🔹 有向图

边有方向，只添加一次：

graph[u].append((v, w))

u → v 表示只能从 u 到 v

🔸 无向图

边无方向，需要添加两次：

graph[u].append((v, w)) graph[v].append((u, w))

u ↔ v 表示双向互通

# Python 邻接表（带权图） from collections import defaultdict V = 5 graph = defaultdict(list) # 批量添加有向边 edges = [ (0, 1, 2), # A -> B (2) (0, 2, 4), # A -> C (4) (1, 2, 1), # B -> C (1) (1, 3, 7), # B -> D (7) (2, 4, 3), # C -> E (3) (3, 4, 2), # D -> E (2) ] for u, v, w in edges: graph[u].append((v, w))
存储方式对比
两种存储方式的选择策略
存储方式 空间 查边 (i, j) 遍历邻居 适用场景
邻接矩阵 O(V²) O(1) O(V) 稠密图、频繁判边
邻接表 O(V + E) O(degree) O(degree) 稀疏图、遍历为主
📌 判断依据：边数 E 接近 V² 选矩阵，否则选邻接表
