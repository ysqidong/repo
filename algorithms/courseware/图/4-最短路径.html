Single-Source Shortest Path · Bellman-Ford · Dijkstra
单源最短路径 · Bellman-Ford · Dijkstra · 理念对比
最短路径问题
从一个起点到所有其他顶点的最短距离
  • 单源最短路径：给定一个起点，求到所有其他顶点的最短距离
  • 经典解法有两种：
    • Bellman-Ford：通用型，能处理负权边
    • Dijkstra：贪心型，非负权图更快
  • 两种算法的核心操作都是松弛（Relaxation）：dist[v] = min(dist[v], dist[u] + w)

核心问题：起点 A 到其他点的最短距离

💡 关键分歧：能不能处理负权边？这决定了你应该选哪个算法
Bellman-Ford 算法
逐轮松弛，地毯式逼近 —— 通用但慢
  • 核心思想：对图中的每条边，重复进行 V-1 轮松弛
  • 每一轮松弛后，距离数组都会更接近真实最短距离
  • 经过 V-1 轮后，所有最短路径都被确定（因为最长简单路径最多 V-1 条边）
  • 额外再做一轮：如果还能松弛，说明存在负权环
  • 时间复杂度：O(V·E)
INF = float('inf') def bellman_ford(graph, V, start): dist = [INF] * V dist[start] = 0 # 对每条边松弛 V-1 轮 for _ in range(V - 1): for u in range(V): for v, w in graph[u]: if dist[u] + w < dist[v]: dist[v] = dist[u] + w # 检测负权环 for u in range(V): for v, w in graph[u]: if dist[u] + w < dist[v]: return None # 存在负权环 return dist
💡 Bellman-Ford 的哲学：不假设任何前提，老老实实地枚举所有边，用足够的轮数确保正确性
Dijkstra 算法
贪心选择 + 松弛 —— 快但有前提
  • 核心思想：每次从未确定的顶点中，选出距离起点最近的一个
  • 选中的顶点距离已确定（贪心），用它去松弛邻居
  • 关键前提：边权必须非负，否则贪心策略会失效
  • 用优先队列（堆）取最近顶点，时间复杂度：O((V+E) log V)
INF = float('inf') import heapq def dijkstra(graph, V, start): dist = [INF] * V dist[start] = 0 pq = [(0, start)] while pq: d, u = heapq.heappop(pq) if d > dist[u]: continue # 跳过过期数据 for v, w in graph[u]: if dist[u] + w < dist[v]: dist[v] = dist[u] + w heapq.heappush(pq, (dist[v], v)) return dist
💡 Dijkstra 的哲学：利用「边权非负」这个条件，每次只做最有把握的决定，不做无用功

🔍 Bellman-Ford 类比

像地毯式排查——不遗漏任何可能，确保结果正确，但耗费时间

🎯 Dijkstra 类比

像策略性搜索——利用已知条件做最优决策，高效但依赖前提

核心差异：Bellman-Ford 用「枚举」换「通用」；Dijkstra 用「前提」换「效率」
负权边：分水岭
为什么一条负权边就能决定算法选择？

Bellman-Ford 如何处理？

  • 第 1 轮松弛后：A→B = 2，A→C = 5
  • 第 2 轮松弛后：发现 C→B = -10，更新 A→C→B = -5
  • 多轮松弛能不断修正之前的结果

Dijkstra 为什么不行？

  • 第 1 步确定 B = 2 后「锁定」
  • 后续发现 A→C→B = -5 时，B 已无法更新
  • 贪心策略的前提（非负权）被打破了

反例：3 顶点带负权边

Dijkstra 确定 B = 2，但真实最短是 A→C→B = -5

💡 选择原则：图中有负权边 → 用 Bellman-Ford；无非负权边 → 用 Dijkstra 更快
