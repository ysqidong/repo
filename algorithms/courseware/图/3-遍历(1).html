Depth-First Search · Breadth-First Search
DFS · BFS · 访问标记 · 连通分量
为什么需要 visited 数组？

树遍历中，每个结点只有一个父结点，从根向下走不会重复访问。

图遍历中，顶点之间可能存在环，也可能通过多条路径到达同一个顶点。

如果不标记已访问，搜索会在环中无限循环，或者在同一个顶点上做大量重复工作。

结论：图遍历必须引入 visited[] 数组（或哈希集合）来记录每个顶点的访问状态。

💡 核心公式：图遍历 = 树遍历 + visited 标记
DFS 深度优先搜索
从起点出发，一路走到底，回溯再探索
  • 核心思想：从起点出发，沿着一条路径尽可能深入，走到尽头后回溯，再探索其他分支
  • 实现方式：天然适合递归；也可用显式栈模拟
  • 关键步骤：访问顶点 → 标记 visited → 递归访问所有未访问邻居

递归实现（Python）

def dfs(u): visited[u] = True for v, w in graph[u]: # w 为边权，遍历时不需要 if not visited[v]: dfs(v)
⏱ 复杂度：时间 O(V + E)，空间 O(V)（递归栈 / 显式栈 + visited 数组）
BFS 广度优先搜索
层层推进，先访问所有邻居，再访问邻居的邻居
  • 核心思想：从起点出发，先访问所有直接邻居，再依次访问邻居的邻居，层层向外推进
  • 数据结构：使用队列（Queue）维护待访问顶点
  • 独特优势：在无权图中，BFS 第一次到达某顶点的路径就是边数最少的最短路径

队列实现（Python）

from collections import deque q = deque() q.append(start) visited[start] = True while q: u = q.popleft() for v, w in graph[u]: if not visited[v]: visited[v] = True q.append(v) # dist[v] = dist[u] + 1 # 如需最短路径，可记录距离
⏱ 复杂度：时间 O(V + E)，空间 O(V)（队列 + visited 数组）· 可求无权图最短路径

特性DFSBFS

🧭 DFS 类比

走迷宫时一条路走到底，遇到死胡同再退回岔路口，选择另一条路继续。

🌊 BFS 类比

像水波纹扩散一样，从起点向四周均匀推进，先近后远，层层覆盖。

图遍历 vs 树遍历 ⭐
特性树遍历图遍历
重复访问不会（无环、有向层次）可能（有环、多条路径）
必要操作无需标记必须 visited 数组
DFS 递归天然安全注意栈深度（大图可能爆栈）
BFS 结果层序编号最短路径边数（无权图）
🔗 知识联结：树的前序遍历 ≈ 图的 DFS；树的层序遍历 = 图的 BFS
遍历的应用与作业
常见应用
  1. 求连通分量：对无向图每个未访问顶点执行一次 DFS/BFS，计数即为连通分量个数
  2. 判断环：DFS 中若遇到已访问且不是当前递归路径父结点的顶点，则存在环（回溯边）
  3. 无权图最短路径：BFS 第一次到达目标顶点时的层数，即为最短路径边数
