什么是最小生成树
从连通无向图中选出总权值最小的树
  • 前提：连通无向图
  • 目标：选 V-1 条边连接所有顶点，且总权值最小
  • 性质：MST 不唯一，但最小权值唯一
  • 与最短路径的区别：MST 关注「连接所有点的最小代价」，不是某两点的最短距离

Prim 算法 ⭐
从任一顶点出发，逐步扩展树
  • 核心思想：维护「当前生成树」到各顶点的最小距离
  • 与 Dijkstra 的区别：Prim 维护的是「到树的最小边权」，Dijkstra 维护的是「到起点的最短路径」
  • 时间复杂度：堆优化 O((V+E) log V)
INF = float('inf') import heapq # Prim 堆优化版，O((V+E) log V) pq = [] dist = [INF] * V used = [False] * V dist[start] = 0 heapq.heappush(pq, (0, start)) while pq: d, u = heapq.heappop(pq) if used[u]: continue # 已加入 MST，跳过 used[u] = True # u 正式加入 MST # ans += d # 累加 MST 总权值 for v, w in graph[u]: if not used[v] and w < dist[v]: dist[v] = w heapq.heappush(pq, (dist[v], v)) # dist[v] 实际存的是 v 到 MST 的最小边权
💡 Prim 和 Dijkstra 的代码结构非常相似，区别只在 used[u] 的位置和更新条件
Kruskal 算法 + 并查集 ⭐
按边权从小到大排序，不形成环就加入
  • 核心思想：全局最优——每次选权值最小的边，只要不形成环
  • 判断环：并查集（Union-Find）
  • 时间复杂度：O(E log E)，主要来自排序
# 初始化：fa = list(range(V)) # 并查集（路径压缩） def find(x): if fa[x] != x: fa[x] = find(fa[x]) return fa[x] def unite(x, y): fa[find(x)] = find(y) # 可优化：按 size / rank 合并
# Kruskal，O(E log E) edges.sort() # 按权值排序 ans = 0 cnt = 0 for w, u, v in edges: if find(u) != find(v): unite(u, v) ans += w cnt += 1 if cnt == V - 1: break # 已选 V-1 条边
💡 并查集的 find 路径压缩让查询近似 O(1)，是 Kruskal 高效的关键
Prim vs Kruskal
维度PrimKruskal
核心数据结构优先队列 + 邻接表边数组 + 并查集
适用图类型稠密图稀疏图
时间复杂度O((V+E) log V)O(E log E)
实现难度与 Dijkstra 类似需实现并查集
核心思想逐步「生长」一棵树从森林合并为一棵树
