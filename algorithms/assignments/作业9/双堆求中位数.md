# 作业9（补充2）：双堆求中位数 — MedianFinder

---

## 一、题目

设计一个数据结构 **MedianFinder**，支持两个操作：

| 操作 | 说明 |
|------|------|
| `addNum(num)` | 添加一个整数 `num` |
| `findMedian()` | 返回当前所有已添加数字的 **中位数** |

**要求：** 用两个堆实现（一个大顶堆 + 一个小顶堆），并分析时间复杂度。

---

## 二、核心思路

### 2.1 为什么用两个堆？

中位数将数据流分成两半：
- **左半部分**：≤ 中位数的所有数
- **右半部分**：≥ 中位数的所有数

只需快速访问左半的最大值和右半的最小值：

```
   左半（较小的一半）         右半（较大的一半）
   ┌────────────────┐       ┌────────────────┐
   │  大顶堆 maxHeap │       │  小顶堆 minHeap │
   │  (取最大值 O(1))│       │  (取最小值 O(1))│
   └───────┬────────┘       └───────┬────────┘
           │                        │
      ┌────┴───┐              ┌────┴───┐
      │   10   │              │   20   │
      │  /  \  │              │  /  \  │
      │ 5    8 │              │ 25  30 │
      └────────┘              └────────┘
      最大值 = 10              最小值 = 20
              ↑                  ↑
              └──── 中位数 ──────┘
              (10+20)/2 = 15
```

### 2.2 不变量（Invariant）

始终维护：

> **`len(maxHeap) == len(minHeap)` 或 `len(maxHeap) == len(minHeap) + 1`**

即：左堆最多比右堆多 1 个元素。

这样中位数的计算极简：

| 两堆大小关系 | 中位数 |
|-------------|--------|
| `maxHeap` 比 `minHeap` 多 1 | `maxHeap.top()`（左堆最大值） |
| 两堆相等 | `(maxHeap.top() + minHeap.top()) / 2.0` |

---

## 三、addNum 流程

```
addNum(num):
    1. 将 num 先放入 maxHeap（左半）
    2. 将 maxHeap 的堆顶（左半最大值）弹出，转入 minHeap（右半）
       → 保证右半所有数 ≥ 左半所有数
    
    3. 平衡大小：
       如果 minHeap 比 maxHeap 大，把 minHeap 堆顶弹回 maxHeap
       → 维持 maxHeap 始终 ≥ minHeap
```

### 图解

```
插入 num = 17（假设当前左堆 [5,8,10]，右堆 [20,25,30]）

Step 1: num 进左堆              Step 2: 左堆最大值弹出进右堆
  maxHeap: [5,8,10,17]           maxHeap: [5,8,10]
  minHeap: [20,25,30]            minHeap: [17,20,25,30]
                                 17 < 20 ✓（右半全部 ≥ 左半）

Step 3: 右堆比左堆大了 → 右堆最小值弹回左堆
  maxHeap: [5,8,10,17]
  minHeap: [20,25,30]
  大小: 4 vs 3 ✓
```

## 四、时间复杂度分析

| 操作 | 时间复杂度 | 解释 |
|------|-----------|------|
| `addNum` | **O(log n)** | 每次最多 2 次 `push` + 2 次 `pop`，堆操作均为 O(log n) |
| `findMedian` | **O(1)** | 直接读堆顶，无需遍历 |
| 空间 | **O(n)** | 存储所有 n 个元素 |

### 为什么不用排序数组？

| 方案 | add | findMedian |
|------|-----|------------|
| 排序数组（每次插入后排序） | O(n log n) | O(1) |
| 插入排序（有序插入） | O(n) | O(1) |
| **双堆（本题方案）** | **O(log n)** ✅ | **O(1)** ✅ |

双堆在 **频繁插入** 场景下碾压排序方案。

---

## 五、运行示例

```
操作序列:
  addNum(10)          → [10],                    中位数 = 10.0
  addNum(20)          → [10, 20],                中位数 = 15.0
  addNum(5)           → [5, 10, 20],             中位数 = 10.0
  addNum(25)          → [5, 10, 20, 25],         中位数 = 15.0
  addNum(30)          → [5, 10, 20, 25, 30],     中位数 = 20.0
```

### 逐步状态

```
addNum(10):          maxHeap=[10]       minHeap=[]          → 中位数=10.0
addNum(20):          maxHeap=[10]       minHeap=[20]        → 中位数=15.0
addNum(5):           maxHeap=[5,10]     minHeap=[20]        → 中位数=10.0
addNum(25):          maxHeap=[5,10]     minHeap=[20,25]     → 中位数=15.0
addNum(30):          maxHeap=[5,10,20]  minHeap=[25,30]     → 中位数=20.0
```

---

## 六、正确性证明（简要）

1. **有序性**：每次插入后，`maxHeap` 中的最大值 ≤ `minHeap` 中的最小值（Step 2 保证）
2. **大小平衡**：`maxHeap` 比 `minHeap` 多 0 或 1 个元素（Step 3 保证）
3. **中位数正确**：有序 + 平衡 → 中位数 = 左堆顶（奇数个）或两堆顶均值（偶数个）

## 七、延伸

| 变体 | 思路 |
|------|------|
| **滑动窗口中位数** | 双堆 + 延迟删除（lazy deletion） |
| **动态第 k 大** | 维护大小为 k 的小顶堆 |
| **99 百分位数** | 两个堆大小比维持 99:1 |

> 双堆思想本质：**用小堆维护分界线，用不变量保证分界线恰好在中位数位置。**
