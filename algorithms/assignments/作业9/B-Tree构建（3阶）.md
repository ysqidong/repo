# 作业9（补充）：3 阶 B-Tree 构建

> 课件来源：`6-数据库中的树.html` Slide 7  
> 键值序列：`[10, 20, 5, 6, 12, 30, 25]`  
> B-Tree 阶数：**m = 3**（每个结点最多 2 个 key，至少 1 个 key）

---

## 一、B-Tree 性质回顾（m = 3）

| 性质 | 规则 |
|------|------|
| ① 每个结点最多 m−1 = **2** 个 key |
| ② 根结点至少 1 个 key，非根至少 ⌈m/2⌉−1 = **1** 个 key |
| ③ 有 k 个 key 的内部结点必有 **k+1** 个孩子 |
| ④ 所有叶子在同一层（完美平衡） |

---

## 二、逐步插入过程

### 步骤 1：插入 10

```
  ┌─────┐
  │ 10  │
  └─────┘
```

结点只有 1 个 key，未超限 ✓

---

### 步骤 2：插入 20

```
  ┌─────────┐
  │ 10  20  │
  └─────────┘
```

结点有 2 个 key，恰好达到上限 ✓

---

### 步骤 3：插入 5 → ⚠️ 结点溢出，分裂

插入后：
```
  ┌──────────────┐
  │ 5  10  20    │ ← 3 个 key，超出上限！
  └──────────────┘
```

**分裂：** 中间 key = **10** 上提为根，左兄弟 `[5]`，右兄弟 `[20]`

```
       ┌─────┐
       │ 10  │
       └──┬──┘
     ┌────┴────┐
  ┌──┴──┐   ┌──┴──┐
  │  5  │   │ 20  │
  └─────┘   └─────┘
```

---

### 步骤 4：插入 6

从根 `[10]` 开始：6 < 10 → 走左孩子 `[5]`。插入 6 → `[5, 6]`，未超限 ✓

```
       ┌─────┐
       │ 10  │
       └──┬──┘
     ┌────┴────┐
  ┌──┴──┐   ┌──┴──┐
  │ 5 6 │   │ 20  │
  └─────┘   └─────┘
```

---

### 步骤 5：插入 12

从根 `[10]` 开始：12 > 10 → 走右孩子 `[20]`。插入 12 → `[12, 20]`，未超限 ✓

```
       ┌─────┐
       │ 10  │
       └──┬──┘
     ┌────┴────┐
  ┌──┴──┐   ┌──┴─────┐
  │ 5 6 │   │ 12 20  │
  └─────┘   └────────┘
```

---

### 步骤 6：插入 30 → ⚠️ 结点溢出，分裂

从根 `[10]` 开始：30 > 10 → 走右孩子 `[12, 20]`。插入 30 → `[12, 20, 30]`，3 个 key 超出上限！

**分裂：** 中间 key = **20** 上提到父结点

父结点 `[10]` 接收 20 → `[10, 20]`，子指针 3 个：`[5,6]` / `[12]` / `[30]`

```
         ┌─────────┐
         │ 10  20  │
         └────┬────┘
     ┌────────┼────────┐
  ┌──┴──┐  ┌──┴──┐  ┌──┴──┐
  │ 5 6 │  │ 12  │  │ 30  │
  └─────┘  └─────┘  └─────┘
```

---

### 步骤 7：插入 25

从根 `[10, 20]` 开始：25 > 20 → 走最右孩子 `[30]`。插入 25 → `[25, 30]`，未超限 ✓

```
         ┌─────────┐
         │ 10  20  │
         └────┬────┘
     ┌────────┼────────┐
  ┌──┴──┐  ┌──┴──┐  ┌──┴─────┐
  │ 5 6 │  │ 12  │  │ 25 30  │
  └─────┘  └─────┘  └────────┘
```

---

## 三、最终 B-Tree 结构

```
                  ┌─────────────┐
                  │   10   20   │     ← 根（内部结点）
                  │ keys = 2    │
                  │ children = 3│
                  └──┬───┬───┬──┘
              ┌──────┘   │   └──────┐
              │          │          │
         ┌────┴────┐ ┌───┴───┐ ┌───┴──────┐
         │   5  6  │ │  12   │ │  25  30  │   ← 叶子结点
         │ keys = 2│ │keys=1 │ │ keys = 2  │
         │ leaf    │ │ leaf  │ │ leaf      │
         └─────────┘ └───────┘ └──────────┘
```

## 四、性质验证

| # | B-Tree 性质（m = 3） | 验证结果 |
|---|---------------------|----------|
| ① | 每个结点 ≤ 2 个 key | ✅ 根 2 个、`[5,6]` 2 个、`[12]` 1 个、`[25,30]` 2 个，全部 ≤ 2 |
| ② | 非根结点 ≥ 1 个 key | ✅ 所有叶子结点都有 ≥ 1 个 key |
| ③ | k 个 key 的内部结点有 k+1 个孩子 | ✅ 根有 2 个 key ↔ 3 个孩子 |
| ④ | 所有叶子在同一层 | ✅ 全部叶子都在第 2 层 |
| ⑤ | 结点内 key 有序 | ✅ `[5,6]`、`[10,20]`、`[25,30]` 均升序 |
| ⑥ | 子树范围正确 | ✅ 左子树 < 10 < 中子树 ∈ (10, 20) < 右子树 > 20 |

---

## 五、查找示例：查找 12

```
根 [10, 20]:  12 > 10 且 12 < 20  →  走中间孩子
叶子 [12]:    找到 12 ✓
```

路径深度 = 2（从根到叶子只需 2 步，B-Tree 通过"矮胖"结构减少磁盘 I/O）。

---

## 六、关键对比：AVL vs B-Tree

| | AVL 树（作业9前半） | B-Tree（本次） |
|---|---|---|
| 每个结点 key 数 | 1 个 | 最多 m−1 个（这里 2 个） |
| 平衡方式 | 旋转（LL/RR/LR/RL） | 分裂/合并 |
| 高度 | 较高（≤ 1.44·log₂n） | 较低（≤ log_⌈m/2⌉(n)） |
| 应用场景 | 内存查找 | 数据库索引、文件系统 |
