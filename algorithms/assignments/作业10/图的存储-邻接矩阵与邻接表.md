# 作业9（补充3）：图的存储 — 邻接矩阵 & 邻接表

> 课件来源：`图/2-图的存储.html` Slide 4  
> 给定一个 **6 顶点无向图**，写出邻接矩阵和邻接表。

---

## 一、原图结构

由课件 SVG 坐标还原（六边形 + 两条交叉对角线）：

```
            A
           /|\
          / | \
         /  |  \
        F   |   B
        |\  |  /|
        | \ | / |
        |  \|/  |
        E---D---C
```

**顶点**：A, B, C, D, E, F

**边**（共 8 条，无向）：

| 边 | 说明 |
|----|------|
| A–B | 六边形上边右 |
| B–C | 六边形右边 |
| C–D | 六边形下边右 |
| D–E | 六边形下边左 |
| E–F | 六边形左边 |
| F–A | 六边形上边左 |
| **A–C** | 对角线（右上↔左下） |
| **B–E** | 对角线（右下↔左上） |

---

## 二、邻接矩阵（Adjacency Matrix）

6×6 矩阵，`1` 表示有边，`0` 表示无边。无向图 → 矩阵对称。

```
       A   B   C   D   E   F
   ┌─────────────────────────┐
A  │  0   1   1   0   0   1  │
B  │  1   0   1   0   1   0  │
C  │  1   1   0   1   0   0  │
D  │  0   0   1   0   1   0  │
E  │  0   1   0   1   0   1  │
F  │  1   0   0   0   1   0  │
   └─────────────────────────┘
```

### 验证对称性

| 位置 | 值 | 对称位置 | 值 | 一致？ |
|------|-----|----------|-----|--------|
| A–B | 1 | B–A | 1 | ✅ |
| A–C | 1 | C–A | 1 | ✅ |
| A–F | 1 | F–A | 1 | ✅ |
| B–C | 1 | C–B | 1 | ✅ |
| B–E | 1 | E–B | 1 | ✅ |
| C–D | 1 | D–C | 1 | ✅ |
| D–E | 1 | E–D | 1 | ✅ |
| E–F | 1 | F–E | 1 | ✅ |

### 度数行和

| 顶点 | 行和 | 实际度数 | 匹配？ |
|------|------|----------|--------|
| A | 3 | A–B, A–C, A–F | ✅ |
| B | 3 | B–A, B–C, B–E | ✅ |
| C | 3 | C–A, C–B, C–D | ✅ |
| D | 2 | D–C, D–E | ✅ |
| E | 3 | E–B, E–D, E–F | ✅ |
| F | 2 | F–A, F–E | ✅ |

---

## 三、邻接表（Adjacency List）

```
A  →  B  →  C  →  F
B  →  A  →  C  →  E
C  →  A  →  B  →  D
D  →  C  →  E
E  →  B  →  D  →  F
F  →  A  →  E
```

每条边的存储次数（无向图 = 每条边存 2 次）：8 × 2 = **16 个链表结点**，等于邻接矩阵中 `1` 的个数。

---

## 四、两种存储方式对比

| 维度 | 邻接矩阵 | 邻接表 |
|------|---------|--------|
| 空间 | O(V²)，始终 V² 大小 | O(V + E)，稀疏图省空间 |
| 判断边 (u,v) 是否存在 | O(1)，直接查 `matrix[u][v]` | O(deg(u))，遍历链表 |
| 遍历顶点的所有邻居 | O(V)，扫描整行 | O(deg(u))，遍历链表 |
| 本题空间 | 6×6 = 36 | 6 + 16 = 22 |
| 适用场景 | 稠密图、频繁查询边 | 稀疏图、频繁遍历邻居 |

### 本题选哪种？

| 项目 | 数值 |
|------|------|
| 顶点数 V | 6 |
| 边数 E | 8 |
| 最大可能边数（无向完全图） | V(V−1)/2 = 15 |
| 密度 | 8/15 ≈ 53% |

密度 53%，属于**中等偏稠密**。邻接矩阵和邻接表差异不大，都可以。但若顶点数扩展到几千而边数仍只有 O(V) 级别，邻接表优势就非常明显了。
