## 二、Bellman-Ford（逐轮松弛）

所有边按字母顺序处理，共 n−1 = 4 轮。

### 初始

```
dist = [A:0,  B:∞,  C:∞,  D:∞,  E:∞]
```

### 第 1 轮（k = 1，最多 1 条边的路径）

| 边 | 操作 | dist 变化 |
|----|------|-----------|
| A→B(4) | min(∞, 0+4) | B = **4** |
| A→D(2) | min(∞, 0+2) | D = **2** |
| B→C(1) | min(∞, 4+1) | C = **5** |
| B→E(5) | min(∞, 4+5) | E = **9** |
| C→E(3) | min(9, 5+3) | E = **8** |
| D→B(1) | min(4, 2+1) | B = **3** ← 关键！同轮内 D 刚被更新，马上作用到 B |
| D→E(4) | min(8, 2+4) | E = **6** |
| E→C(2) | min(5, 6+2) | C = 5（不变） |

```
第1轮后: dist = [A:0,  B:3,  C:5,  D:2,  E:6]
```

### 第 2 轮（k = 2，最多 2 条边的路径）

| 边 | 操作 | dist 变化 |
|----|------|-----------|
| A→B(4) | min(3, 0+4) | 不变 |
| A→D(2) | min(2, 0+2) | 不变 |
| B→C(1) | min(5, 3+1) | C = **4** |
| B→E(5) | min(6, 3+5) | 不变 |
| C→E(3) | min(6, 4+3) | 不变 |
| D→B(1) | min(3, 2+1) | 不变 |
| D→E(4) | min(6, 2+4) | 不变 |
| E→C(2) | min(4, 6+2) | 不变 |

```
第2轮后: dist = [A:0,  B:3,  C:4,  D:2,  E:6]
```

### 第 3 轮（k = 3）

所有边均无法再更新 dist，无变化。

### 第 4 轮（k = 4）

同样无变化。无负环（有负环时第 n 轮仍会变化）。

### 最终结果

```
        A ─→ B ─→ C
        │   ↑
        └→ D ─┘
              └──→ E (D→E: 2+4=6, 也是 C→E: 0→A→D→B→C→E = 2+1+1+3 = 7, 不优)

dist = [A:0,  B:3,  C:4,  D:2,  E:6]
```

| 目标 | 最短路径 | 距离 |
|------|----------|------|
| A | — | 0 |
| B | A → D → B | 3 |
| C | A → D → B → C | 4 |
| D | A → D | 2 |
| E | A → D → E | 6 |

## 三、Dijkstra（贪心 + 优先队列）

### 步骤明细

**初始**
```
dist = [A:0,  B:∞,  C:∞,  D:∞,  E:∞]
未确认 = {A, B, C, D, E}
```

**Step 1：选 A（dist=0），确认**
```
松弛 A→B(4): B = min(∞, 0+4) = 4
松弛 A→D(2): D = min(∞, 0+2) = 2

dist = [A:0✓,  B:4,  C:∞,  D:2,  E:∞]
```

**Step 2：选 D（dist=2），确认**
```
松弛 D→B(1): B = min(4, 2+1) = 3
松弛 D→E(4): E = min(∞, 2+4) = 6

dist = [A:0✓,  B:3,  C:∞,  D:2✓,  E:6]
```

**Step 3：选 B（dist=3），确认**
```
松弛 B→C(1): C = min(∞, 3+1) = 4
松弛 B→E(5): E = min(6, 3+5) = 6

dist = [A:0✓,  B:3✓,  C:4,  D:2✓,  E:6]
```

**Step 4：选 C（dist=4），确认**
```
松弛 C→E(3): E = min(6, 4+3) = 6

dist = [A:0✓,  B:3✓,  C:4✓,  D:2✓,  E:6]
```

**Step 5：选 E（dist=6），确认**
```
松弛 E→C(2): C 已确认，跳过

dist = [A:0✓,  B:3✓,  C:4✓,  D:2✓,  E:6✓]
```

### 结果

与 Bellman-Ford 完全一致（所有边权非负，必然一致）。

## 四、为什么 Dijkstra 怕负权边而 Bellman-Ford 不怕？

### Dijkstra：贪心的代价

```
Dijkstra 每一步从"未确认顶点"中取出 dist 最小的，
立即"确认"它——从此不再修改。

这依赖一个前提：
  "当前 dist 最小的未确认顶点，它的最短距离已经不可能被后面的路径改得更小了"
  → 这个前提只有在所有边权 ≥ 0 时才成立。

反例（有负权边）：
  A ──1──→ B
  A ──100→ C
  C ─(-99)→ B

  Dijkstra 步骤：
    Step 1: 确认 A(0)
    Step 2: 确认 B(1) ← 此时 dist[B]=1, dist[C]=100
                       B 被永久锁定为 1
    Step 3: 确认 C(100)，松弛 C→B: B = min(1, 100-99) = 1
            发现不了真正最短路径 A→C→B = 1

  真正答案应该是 A→C→B = 100 + (-99) = 1，但 Dijkstra 漏掉了。
  （虽然这个例子恰好结果一样，但如果有 A→100→B 对比，问题就暴露了）
```

更直观的反例：
```
  A ──2──→ B
  A ──3──→ C
  C ─(-2)─→ B

  Dijkstra: 选 A→确认 A→确认 B(2)→确认 C(3)→C→B 试图松弛时 B 已锁死
  正确结果: A→C→B = 3+(-2) = 1，但 Dijkstra 输出 2
```

### Bellman-Ford：暴力的正确

```
Bellman-Ford 不做任何"确认"操作。每一轮把所有边全部松弛一遍，
n-1 轮后，所有 ≤ n-1 条边的最短路径都被穷举过了。

它不依赖"边权非负"这个前提——正也好负也好，每轮都老老实实过一遍，
没有任何顶点被"提前锁定"。
```

### 一句话总结

| | 核心思想 | 为什么怕负权 |
|---|---|---|
| **Dijkstra** | 贪心：每次锁定当前最小的那个 | 锁定后无法回头修正 |
| **Bellman-Ford** | 暴力：每轮把所有边全过一遍 | 不怕，每轮都有机会修正 |

Dijkstra 用 **正确性换速度**（限定非负权 → O((V+E) log V)）；  
Bellman-Ford 用 **速度换通用性**（什么权都能处理 → O(VE)）。

## 五、最终对比表

| | Bellman-Ford | Dijkstra |
|---|---|---|
| 本题 dist 结果 | [A:0, B:3, C:4, D:2, E:6] | [A:0, B:3, C:4, D:2, E:6] |
| 计算轮次/步数 | 4 轮（n−1），第 3 轮起无变化 | 5 步（每步确认 1 顶点） |
| 负权边 | ✅ | ❌ |
| 负环检测 | ✅ 第 n 轮还能变 | ❌ |
| 时间复杂度 | O(VE) | O((V+E) log V) |
| 核心数据结构 | 边列表 | 优先队列 |
