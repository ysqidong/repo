# 作业10（补充）：图的遍历 — DFS & BFS

> 课件来源：`图/3-遍历(1).html` Slide 6  
> 给定 5 顶点无向图，写出从 A 出发的 DFS 和 BFS 遍历序列（邻接点按字母顺序）。

---

## 一、原图结构

```
             A
            / \
           /   \
          B     C
          |    / \
          |   /   \
          D--+-----E
```

**邻接表**（字母序）：

```
A → B → C
B → A → D
C → A → D → E
D → B → C → E
E → C → D
```

---

## 二、DFS（深度优先）—— 用栈

**原则**：能走多远走多远，走不动了回溯。

```
初始栈 = [A]，visited = {}

Step 1: 弹出 A，访问 A → visited = {A}
        A 的邻居 B、C 未访问，按字母序压栈 → 栈 = [C, B]  (C先压, B后压则在栈顶)

Step 2: 弹出 B，访问 B → visited = {A, B}
        B 的邻居 D 未访问(A已访问) → 压栈 → 栈 = [C, D]

Step 3: 弹出 D，访问 D → visited = {A, B, D}
        D 的邻居 C、E 未访问 → 压栈 → 栈 = [C, E, C]

Step 4: 弹出 C，访问 C → visited = {A, B, D, C}
        C 的邻居 E 未访问 → 压栈 → 栈 = [C, E, E]

Step 5: 弹出 E，访问 E → visited = {A, B, D, C, E}
        E 的邻居都已访问

Step 6: 弹出 E(重复)，跳过 → 弹出 C(重复)，跳过 → 栈空，结束
```

### DFS 遍历序列

```
A → B → D → C → E
```

### DFS 生成树

```
       A
       |
       B
       |
       D
      / \
     C   (C-D 是树边)
     |
     E
```

树边：A-B, B-D, D-C, C-E（共 4 条，V−1=4 ✓）

---

## 三、BFS（广度优先）—— 用队列

**原则**：一层一层往外走，先近后远。

```
初始队列 = [A]，visited = {}

Step 1: A 出队，访问 A → visited = {A}
        A 的邻居 B、C 按序入队 → 队列 = [B, C]

Step 2: B 出队，访问 B → visited = {A, B}
        B 的邻居 D 入队(A 已访问) → 队列 = [C, D]

Step 3: C 出队，访问 C → visited = {A, B, C}
        C 的邻居 E 入队(D 已入队/将访问) → 队列 = [D, E]

Step 4: D 出队，访问 D → visited = {A, B, C, D}
        D 的邻居都已访问/入队 → 队列 = [E]

Step 5: E 出队，访问 E → visited = {A, B, C, D, E}
        队列空，结束
```

### BFS 遍历序列

```
A → B → C → D → E
```

### 层次划分

```
第 0 层（距 A = 0）:  A
第 1 层（距 A = 1）:  B, C
第 2 层（距 A = 2）:  D, E
```

### BFS 生成树

```
       A
      / \
     B   C
     |   |
     D   E
```

树边：A-B, A-C, B-D, C-E（共 4 条，V−1=4 ✓）

---

## 四、DFS vs BFS 对比

| | DFS | BFS |
|---|---|---|
| 数据结构 | 栈（递归/显式栈） | 队列 |
| 遍历序列 | **A B D C E** | **A B C D E** |
| 生成树形状 | 一条长链 + 分枝 | 一层层展开 |
| 空间 | O(h)，h 为树高 | O(w)，w 为最宽层 |
| 无权最短路径 | ❌ 不保证 | ✅ BFS 找的是最短路径 |
| 连通性检测 | ✅ | ✅ |
| 环检测 | ✅（回溯边） | ✅（横边/已访问） |

---

## 五、一句话总结

| 场景 | 选谁 |
|------|------|
| 找无权图最短路径 | **BFS** |
| 走迷宫、拓扑排序、强连通分量 | **DFS** |
| 生成树形状重要（想要更"宽"的树） | **BFS** |
| 递归思路自然（回溯、排列组合） | **DFS** |
